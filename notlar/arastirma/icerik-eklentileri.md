# Free custom-content stack for Paper 26.2 + Velocity + Geyser/Floodgate (researched 2026-09-29)

**How this was checked.** My sandbox could open github.com and raw.githubusercontent.com, so every GitHub claim below comes from a page I read myself: READMEs, release pages, commit lists, wiki pages and config files. Modrinth, Hangar, SpigotMC, mythiccraft.io, geysermc.org, the Nexo and ItemsAdder docs, and deepwiki were blocked. Anything from those sources comes only from search-result snippets and is marked (snippet). Anything I couldn't confirm is marked UNVERIFIED.

Some GitHub release pages showed the wrong year (2024 or 2025) for releases that clearly target 26.x. I fixed those dates using the commit history and the version numbers.

**One thing to know first:** the Geyser README says it supports Java **"26.2"** and Bedrock "26.30 … 26.51". So stay on Paper 26.2 until Geyser adds 26.3.

### How BetterModel works (from its wiki and source)

- **Blockbench format:** "you should generate your model as **Generic model**." Put the files in `plugins/BetterModel/models`. Player-only animations go in `plugins/BetterModel/players`: open the bundled `steve.bbmodel` and animate that. Mesh elements need BetterModel 3.0.0+ and a 26.1+ client. Blockbench 4 and 5 are both supported. Billboards, splines and armatures are not.
- **Bone tags** (prefix + `_`, e.g. `h_head`; exact list from `BoneTags.java`):

  | Tag | Effect |
  |---|---|
  | `h` | Follows the entity's head rotation |
  | `hi` | Same, but children follow too ("head with children") |
  | `b` or `ob`, or a group named `hitbox` | Creates a hitbox that follows the bone |
  | `p` | Controllable seat |
  | `sp` | Seat that can't be controlled |
  | `tag` / `mtag` / `ptag` | Nametag / mob nametag (visible when looking at it) / player nametag (always visible) |
  | `glow` | Glow |
  | `li`/`pli`, `ri`/`pri` | Item held in left / right hand |

  Player limbs: `ph` head, `pc` chest, `pw` waist, `phip` hip, `pra`/`prfa` right arm/forearm, `pla`/`plfa` left arm/forearm, `prl`/`prfl` right leg/foreleg, `pll`/`plfl` left leg/foreleg, `cape`.
- **Animations:** these names play automatically: `idle, spawn, death, walk, idle_fly, walk_fly, jump`. Loop, play-once and hold-on-last are all supported. To trigger them manually:
  - Test: `/bm test <model> <animation>`
  - Spawn a model: `/bettermodel spawn <model> [entity type] [scale]`
  - Player emotes: `/bm play <limb> <animation>`
  - Or through the API or MythicMobs.
- **MythicMobs mechanics** follow ModelEngine's syntax, e.g. `model{mid=…;s=…}` and `state{s=…;li=;lo=;sp=}`. Also available: `defaultstate`, `partvisibility`, `changepart`, `tint`, `brightness`, `glow`, `enchant`, `bindhitbox`, `mountmodel`, `dismountmodel`, `dismountallmodel`, `bodyrotation`, `lockmodel`, `remapmodel`, `pairmodel` (experimental); the `modelpart` targeter; the `modelhaspassenger` condition. You can turn the MythicMobs module off with `module.model: false` in `config.yml`.

## Recommended free stack (one pick per category)

1. **Items, blocks and furniture: CraftEngine Community Edition.** It's the only actively maintained GPL, config-driven option covering items, real blocks and furniture. The code supports up to 26.3, and it merges BetterModel's pack by default. Oraxen, Nexo and ItemsAdder are all paid.
2. **Mob and boss models: BetterModel (MIT) + MythicMobs Free 5.13.0, modelled in Blockbench 5.2.1.** Fully free, even snapshot builds, and it states 26.2 support directly. It uses ModelEngine-style MythicMobs syntax and simple bone tags, and it includes player emotes. Fallback if Bedrock visibility of mobs matters most: FreeMinecraftModels, which has its own Bedrock backend.
3. **Bedrock: Rainbow** (generates Geyser v2 mappings and the Bedrock pack from your CraftEngine pack). Add GeyserDisplayEntity for furniture and GeyserModelEngine + GeyserUtils for BetterModel mobs, but only after testing them on a 26.2 staging server because of issue #74. All are free and open source. Accept that some things will look worse on Bedrock.
4. **Pack delivery: CraftEngine's built-in self-host.** One source of truth, with rate limits and one-time tokens, and no third-party upload. Add ForcePack on Velocity only if you need network-wide enforcement. Treat PackSquash as optional until a release after 0.4.1 ships.
